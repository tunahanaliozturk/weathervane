# Changelog

## Unreleased

First version.

- Flags with boolean, string, number and JSON variations, configured per environment with an on/off
  switch, ordered targeting rules and percentage rollouts.
- Management API for projects, keys, flags, configs and the audit log. Config writes need `If-Match`
  and a stale version gets `412`.
- SDK API: the ruleset with `ETag`, an evaluate endpoint that explains each result, and a server-sent
  event stream that resumes from `Last-Event-ID`.
- Changes reach other instances through Postgres `LISTEN/NOTIFY`, sent only on commit.
- Node SDK with local evaluation, reconnect with jitter, an idle watchdog, and typed reads generated by
  `weathervane-typegen`.
- Docker image and a compose stack, with a quick start that CI runs.
